# F15: Quick-log actions and sequence automation

- **Priority:** P0 · **Release:** R4 (v1.3.0) · **Status:** Planned
- **PRD:** [Business rules → Quick-log automation](../PRD.md)

## What it does

Buttons on the person detail page (Request sent, Accepted, Message 1 sent, Follow-up sent, Got a reply, Demo booked, Demo held, Mark converted, Mark lost). Each logs an activity, then sets stage, sequence step and next action automatically, using the Playbook Settings delays. Users can't log outreach on someone else's lead.
