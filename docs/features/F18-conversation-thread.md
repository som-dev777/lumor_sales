- **Priority:** P0 · **Release:** R8 (v2.2.0) · **Status:** Planned

## What it does

A chat-style thread replaces the timeline on each person's page. When a reply is pasted, the
AI (P02, extended) suggests responses and an expected-reply deadline, which the rep confirms.
An expired deadline becomes a nudge task on Today, with at most 2 nudges per open question.

This is a placeholder. The full doc is written before any code, at the start of R8. R7 already
adds the `awaiting_reply_until` field and Today's "Expired reply deadlines" section.
