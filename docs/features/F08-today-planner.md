## What it does

The home page. A rule-based daily task list (replies waiting, demos and recaps, follow-ups due, requests to withdraw, new outreach target, stale leads), ranked and explained by AI prompt P01. It also has a target progress bar and a 2-sentence weekly summary. Done logs the matching activity; Snooze moves a task to tomorrow. If the AI fails, the unranked list shows.
